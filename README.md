# 💧 Water Hero
## Smart Water Consumption Tracker
**Monitor • Calculate • Save Money**
### What is Water Hero?
A smart web application that helps you track daily water consumption and calculate financial costs. With a modern interface and interactive tools, you can monitor your water habits and improve them effortlessly.
## ✨ Key Features
- 📊 **Instant Analytics** — Get detailed statistics about water consumption daily, weekly, and monthly.
- 💰 **Cost Calculation** — Calculate the cost of each water activity and monitor your spending precisely.
- 🧮 **Consumption Simulator** — Try different activities and predict your consumption before performing them.
- 💡 **Smart Tips** — Get practical tips for saving water and protecting the environment.
- 📱 **Modern Interface** — Beautiful and smooth design that works perfectly on all devices and screens.
- 💾 **Local Storage** — Safe data stored on your device without requiring internet connection.

## 🎯 Application Sections
- 🏠 **Home** — Main dashboard displaying today's consumption, costs, and quick statistics.
- 🧮 **Calculator** — Interactive simulator to calculate water consumption before performing activities.
- ➕ **Add Activity** — Easily record water activities by selecting activity type and duration.
- 💡 **Tips** — Practical and effective tips for water conservation and reducing waste.
- ℹ️ **About** — Information about the application, developer, and future vision.

## 🚀 How to Use 

1. **Open the Application** — Use the HTML file directly in your browser without any installation.
2. **Select an Activity** — Click on a water activity from the available activities list.
3. **Enter Duration** — Specify the number of minutes the activity took.
4. **Get Statistics** — View detailed reports about your consumption and costs.

## 🛠️ Technical Requirements

### Requirements

- Modern browser (Chrome, Firefox, Safari, Edge)
- JavaScript enabled
- Local Storage support
- Screen minimum 320px width

### Technologies Used

- HTML5 + CSS3 + JavaScript
- Tailwind CSS for styling
- Bilingual support (Arabic & English)
- Secure local data storage

## 📥 Installation & Usage

- ✅ **Very Easy:** Save the HTML file and open it directly in your browser.
- ✅ **No Internet Required:** Works completely offline.
- ✅ **Safe and Fast:** Your data is stored locally on your device only.
- ✅ **Full Compatibility:** Works on phones, tablets, and computers.
